## 🤖 AI Projects

### Rick Bot: Personal AI Agent
`🚧 In development` · `Source code private`

A Telegram-based personal assistant built on the **Claude API** that can act on my behalf across GitHub, Notion and Google Calendar.

- **Custom agent loop:** Claude decides when to call a tool, the bot executes it and feeds the result back, with a bounded number of iterations per request
- **Tool registry:** modular tools for GitHub, Notion, Google Calendar and time, each with retry handling for network errors
- **Human in the loop:** destructive actions need a confirmation from the user in a separate message, so the model cannot approve its own request
- **Proactive behaviour:** scheduled morning and evening briefings, plus event reminders that run without any LLM calls
- **Safety and reliability:** single-user authorization, conversation memory limits and a unit test suite for every tool

<sub>**Python · Claude API · Tool Use · python-telegram-bot · Notion API · Google Calendar API · pytest**</sub>
